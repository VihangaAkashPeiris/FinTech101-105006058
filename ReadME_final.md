# SMS Spam Detection System

This project implements a complete SMS spam detection pipeline consisting of three sequential modules: classification, probability scoring, and clustering. The system can classify messages as spam or ham, estimate spam and ham probabilities, and group spam messages into topic categories such as promotions or phishing. All models are built from scratch using Python and scikit-learn.

---

## Overview

The final model (`cluster_model.py`) integrates all components. On first execution, it trains and saves the required `.joblib` files. On later runs, it loads the pre-trained models and provides an interactive console where the user can enter any message and view its classification, probabilities, and spam category.

**Project Flow**
```
SMS_Classifier.py → SMS_Prob.py → cluster_model.py
(merge.py is used only to prepare spam-only datasets for clustering)
```

## 3. Dataset Preparation

### Step 1: Prepare Spam-Only Dataset

The spam-only dataset required for clustering is generated by merging two sources:

- **UCI SMS Spam Collection (`spam.csv`)**
- **SpamAssassin Spam Clean Dataset (`spamassassin_spam_clean.csv`)**

Run the following command to generate the merged datasets:

```bash
python merge.py
```

This creates two files in the `Datasets/` directory:
- `Spam_cleaned.csv` – UCI spam messages only  
- `spam_only_merged.csv` – Combined spam dataset for clustering

---

## 4. Model Training

The models can be trained step-by-step or automatically through the final integrated file.

### Option 1: Train Manually (Step-by-Step)

#### (a) SMS Classifier

```bash
python SMS_Classifier.py
```
- Reads `Datasets/spam_d.csv`
- Vectorizes text using TF‑IDF
- Trains a **Logistic Regression** classifier
- Prints accuracy, confusion matrix, and classification report
- Saves model as `spam_model.joblib`

#### (b) Probability Model

```bash
python SMS_Prob.py
```
- Loads trained classifier
- Trains a **Ridge Regression** model to estimate spam and ham probabilities
- Adds interpretability by providing a continuous spam likelihood (0–1)

#### (c) Clustering Model

```bash
python cluster_model.py
```
- Uses `spam_only_merged.csv`
- Vectorizes spam text and applies **K‑Means clustering**
- Groups spam into semantic categories (e.g., offers, finance, scams)
- Saves trained bundle as `spam_kmeans_bundle.joblib`

### Option 2: Train and Run Automatically

Running the final model will check for saved `.joblib` files. If missing, it will train and save them automatically:

```bash
python cluster_model.py
```

## 6. Evaluation Metrics

During training, evaluation results such as the confusion matrix and classification report are printed to the terminal.

Example snippet:
```python
print("Confusion Matrix:\n", confusion_matrix(y_test, y_pred))
print("\nClassification Report:\n", classification_report(y_test, y_pred, target_names=['Ham', 'Spam']))
```

Typical outputs include precision, recall, F1-score, and overall accuracy.  
For clustering, silhouette scores may be used to assess cluster quality.

## 7. Saved Models and Reuse

After the first run, the following models are saved automatically:
- `spam_model.joblib` – Spam/Ham classifier
- `spam_kmeans_bundle.joblib` – K‑Means spam clustering model

These files are loaded on subsequent runs to save time.

If retraining is required, simply delete the existing `.joblib` files and re-run the scripts.

## 8. Troubleshooting

| Issue | Cause | Solution |
|-------|--------|-----------|
| `FileNotFoundError` | Missing dataset files | Verify all CSV files are in the `Datasets/` folder |
| Encoding error | Non‑UTF8 characters | Open CSV with `encoding='latin-1'` |
| GitHub push error for `.joblib` files | File size limit exceeded | Add `*.joblib` to `.gitignore` or use Git LFS |
| Wrong predictions | Unclean or imbalanced dataset | Re‑train the model after cleaning data |
